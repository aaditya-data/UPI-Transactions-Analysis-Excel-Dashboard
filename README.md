# 📊 UPI Transactions Analysis Dashboard (Excel)

An interactive Microsoft Excel dashboard built to analyze **502,887 UPI transactions** worth **₹44.25 Cr**. The project demonstrates end-to-end data analysis using Excel, including data cleaning, transformation, visualization, and business insights.

---

## 📌 Project Overview

The objective of this project is to analyze UPI transaction data to understand:

- Transaction trends
- Payment platform performance
- Regional transaction distribution
- Banking performance
- Transaction success rate
- Hourly transaction behavior
- Fraud monitoring
- Cashback analysis

The dashboard enables users to interactively filter data and explore key performance metrics.

---

## 🎯 Business Objectives

- Monitor overall UPI transaction performance
- Identify the most used UPI applications

## 📈 Key Insights

### Overall Performance

- Processed **502,887 transactions**
- Total transaction value exceeded **₹44.25 Cr**
- Achieved a **91.0% success rate**

### UPI Apps

- PhonePe contributes nearly **50%** of total transaction value.
- Google Pay is the second-largest payment platform.

### Regional Analysis

- Maharashtra records the highest transaction value.
- Southern and western states contribute significantly to UPI activity.

### Peak Usage

- Highest transaction activity occurs between **7 PM and 9 PM**.

### Banking Performance

- HDFC Bank processes the highest transaction value among listed banks.

### Fraud Monitoring

- Approximately **17,000 transactions** are flagged as suspected fraud, highlighting the importance of continuous monitoring.
